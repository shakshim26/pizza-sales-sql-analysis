# 🍕 Pizza Sales SQL Analysis

This is a simple SQL project where I analyzed pizza sales data to understand how the business is performing.

I worked on things like total revenue, revenue by category, top-selling pizzas, average orders per day, and how revenue grows over time. I used SQL concepts like joins, group by, and window functions to solve these.

All queries are added in the SQL file, and screenshots of outputs are included for better understanding.

This project is part of my practice to improve my SQL and data analysis skills.
